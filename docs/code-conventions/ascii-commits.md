# ASCII commits and PR text

- Commit subjects and bodies use ASCII punctuation: `--`, `...`, straight quotes.
- No typographic em dash, ellipsis, or curly quotes in commits or PR titles/bodies.
- Present-tense messages; one logical change per commit.
- PR titles carry the ticket code (for example `NV-11 ...`); ticket codes stay out of tracked file contents.
- See also [no-ai-attribution.md](./no-ai-attribution.md).
