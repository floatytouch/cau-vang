# Comments

Comments are the last resort, and only for WHY.

- Prefer rename, extract, and structure so the code explains itself.
- A comment is allowed only when the code cannot carry the reason (external constraint, workaround, landmine).
- One short line, self-contained; no dates, authors, or ticket pointers.
- Banned: restating the next line, section banners, commented-out code.
- Longer context belongs in the commit message.
